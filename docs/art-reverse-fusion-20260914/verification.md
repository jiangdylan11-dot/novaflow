# 美工提示词融合验证（2026-09-14）

用户要求：本地与 Grok 都要覆盖图片反推后的补充要求，以及不带图片的纯提示词优化。新增要求应落实到最终正文，替换冲突旧描述，保留未要求修改的内容。

## 修复

- 美工 AI 助手直接显示 Grok / 本地处理方式，不再折叠在高级设置中。
- 静态图片反推在安全检查通过后，将已识别的画面和用户补充要求送入文字融合阶段；融合成功后才写回。处理失败、内容需确认或请求已过期时不写回。
- 普通美工文字优化与上述第二阶段使用相同融合入口。原有机器结构化六段协议保留独立编译路径。
- 普通正文的融合输出完整提示词，取消原来最多四个局部补丁、合计 320 字对综合优化的限制。未要求改变的设定仍需保留；本地保留单一软化轮廓的确定性编辑，以及旧模型补丁响应的兼容解析。
- 旧的 `[用户附加要求]` / “只作为最终提示词约束，不作为图片可见事实”尾段会从事实底稿中分离，作为修改要求参与融合。
- 新增空结果、照搬、遗漏段落、漏改主体/背景、室外场景残留白底、资源引用丢失等检查。本地不合格结果最多修复一次。
- 对“增加室外背景并提升质量/细节”场景，若模型残留“背景完全虚化”，统一调整为保留室外环境层次。用户明确要求保留虚化时不作此调整。
- 本地普通全文融合的运行时预算扩展到 900 秒，与精简补丁任务区分；不会据此自动增加生成内容。模型输出预算随原文长度增长并设上限。
