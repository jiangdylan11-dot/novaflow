# 雅典娜视频取帧与失败恢复

2026-09-14，版本 2.3.214，不升级版本号。

## 原因及修正

1. RVFC 已确认目标帧后，播放时钟仍可能前进超过半帧。旧链路在回调之后检查 currentTime 并再次读视频，造成误报或读到后续画面。现在在经过时间验证的 RVFC 回调内冻结像素，并将这份像素直接交给 AI。只在存在已验证像素时允许播放时钟不同；没有回调、错误帧或快照失败仍然失败。
2. 雅典娜末帧的直接 seek 有时不能触发对应 RVFC。转码副本进入 ended 后 play 会回到开头；原文件因音频尾部更长，Chromium 的 duration 为 4.885333 秒，视频轨道为 4.875 秒，ended 判断又可能不成立。现在对最后一个计划帧明确从前一帧播放进入目标帧，再以真实 mediaTime 验证和冻结，保留 117 帧。
3. 旧失败处理只清 React 抠图状态，外层仍保留编辑状态及帧模式，原视频继续隐藏。现在同时退出帧模式、释放外层编辑状态和媒体显示所有权，并保留可关闭的错误提示。
