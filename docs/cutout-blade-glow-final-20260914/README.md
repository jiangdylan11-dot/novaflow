# 剑柄光晕局部修正

缺失来自人物轮廓去污染步骤对贴近剑柄的光晕过度抑制。只在主体外侧、原片有连续宽光晕、颜色一致且没有绿幕吸收证据时，保护原有光能；细窄的绿边继续清理。没有重画或补造光效。

修正前后使用同一次解码的 RGB 与同一次真实 AI 输出。页面视频由真实导出的透明 PNG 直接合成，未再做图像后期。
