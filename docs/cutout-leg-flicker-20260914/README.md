# 雅典娜腿部闪白：局部修正

本次基于用户刚认可的“视频抠图统一版”，没有更换抠图方案、按钮或参数。旧的认可安装包和对比材料均保留。

原因：不透明腿部轮廓经过参考帧的薄纱区域时，周围小块纹理仍能匹配薄纱。旧代码会把参考薄纱颜色和较低透明度混入腿部，产生原片没有的浅色横纹。修正增加当前帧的不透明证据保护，并对弱材质证据连续过渡；正常薄纱继续使用原有恢复。

验证内容：

- 共 40 项抠图、光效、投影、运动和透明视频编码测试通过。
- 五段原视频通过当前按钮执行实际 PNG 导出，回放同一批真实 AI 遮罩，按实际捕获原图匹配，避免模型变化干扰对比。未重新运行 AI 模型。
- 两版源 RGB 一致；逐像素差异与区域统计见 pixel-comparison.json。
