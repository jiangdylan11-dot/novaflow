# 薄纱局部闪动验收

基线为你反馈“好很多了，只有一点闪”的 edfa32dddda8 版本。保留该版本，只修改薄纱的参考位置匹配。

## 这次处理

- 将整数位置匹配细化到亚像素，减少微小动作引起的位置跳动。
- 对少量孤立亮点降低匹配影响；整片变亮、大片光效和暗色材质边缘保留普通匹配。
- 只在亮点干扰且周围匹配可靠的位置约束异常位移。没有跨帧平均最终画面，没有固定人物坐标，也没有按金色或其他特定光效颜色写规则。
- 人物边缘、投影、透明光效重建、笔刷、保存关闭和界面规则未修改。实际代码差异限定在 materialMotion，详见 code-scope.json。

## 看结果

打开 index.html 检查五段视频和透明 PNG；gloweyes-detail.mp4 是你指出区域的放大动态对比。左侧为认可基线，右侧为本次结果。正常光点仍会闪烁，重点观察薄纱自身的透明度是否平稳。
