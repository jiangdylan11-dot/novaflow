# H3 分模式修复验证（2026-09-14）

本轮按用户的六张截图拆分优化、视觉分析、界面写回与格式展示问题。测试使用已有的中性赛博角色素材和待机呼吸提示词；不等同于用户原素材验收。

## 确认与修复

1. 正式客户端日志：T2VA 两次“缺少分时段动作”；Ref2VA 先缺少分时段、再引用错误。真实测试还发现模型重复同一句话填三阶段。现在本地模型只负责起始、递进、收束动作，程序负责五段标题、连续时间、实际媒体标签和原台词。重复阶段被拒绝，缺失或额外引用仍然被拒绝。
2. 本地 I2VA、FL2VA 反推日志均在第一张图以 slot-order 阻断。解析器改为按 S/R/E/L/C 字段名读取，兼容顺序和换行差异；缺失、重复、未知字段、过长值和后续视觉事实检查仍生效。字段值使用 JSON 引号转义后投影。
3. Grok 单图反推实际复现“后端成功、界面拒绝”：待机呼吸结果未命中动作递进关键词。界面现在接受呼吸、起伏、待机和明确静止要求；普通静态图片说明仍须通过原有检查。
4. Grok 五段视觉事实按已识别的标题归位，不再依赖顺序；重复或未知标题不能覆盖原字段。
5. 反推在通过视觉事实和原 H3 协议检查后，由展示转换器转成任务定位、说话者、递进式详细提示词、台词、连续性与约束。保留验证后的事实、声音、参考帧与用户动作；不调用第二个模型伪造格式补充。
6. 界面不再虚报“已自动重试 1 次”。四个相关脚本刷新缓存版本。
