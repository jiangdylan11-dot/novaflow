# H3 多参图片、视频与音频：实现与实际验证

2026-09-14。验收素材为用户提供的 150×150 透明美元金币图和金币旋转视频。

## 实现

- 多参专用六字段协议：主体定义、任务类型、分别保留哪些视觉/声音属性、镜头描述、环境声音和配乐。图片外观、视频动作以及音频角色分别绑定；静物也可以作为主体，不再只定义说话者。
- 点击生成时，旧五段提示词或自由文本先通过本地助手整理为多参协议，再校验素材标签并提交。已有有效六字段提示词直接使用。失败会保留原文并阻止错误提交，不通过补几个标签伪装成功。
- 本地助手生成实际任务关系，程序负责字段格式、标签和明确要求的循环衔接。云端助手也使用相同六字段协议；后端已部署为版本 66。
- 小图进入 H3 前补足输入尺寸。对于明确的视频内容替换，仅在检测到纯色背景、一个独立主体且没有触边时，才根据视频构图合成透明图片，并把视频主体纹样转成中性运动轮廓。复杂背景、多主体、边界不明确时保留原视频，不猜测抠图区域。
- 声音风格/节奏参考进入 H3 音频条件。明确的完整音轨复用同时进入音频条件，并将原音轨裁到视频长度后直接送入视频封装，不用模型重新生成的声音替代它。音频单独作为参考也可提交；视频内嵌音轨不冒充独立声音参考槽。
- 节点随桌面程序交付，由隔离 H3 Runtime 自动加载。升级节点前检查队列，不中断正在生成的任务。整理提示词前检查生成队列并释放空闲模型显存。
