# H3 多参编辑：真实调用与效果记录（2026-09-15）

H3 有视频编辑能力，但开源本地链路不能等同于可灵 OMNI 或 MiniMax 完整托管服务的效果保证。本次修复的是 NovaFlow 对用户意图、素材关系、中文显示及原视频时序的处理；生成效果另行记录，不能用格式校验通过代替。

## 本次改动

- 本地 H3 多参优化优先使用已安装的 Qwen3-VL 指令模型。先理解本次使用的素材及修改范围，再分别观察素材，最后编写编辑后的画面。未安装该指令模型时保留原提供器回退，不自动下载或转用云服务。
- 素材编号、六段协议、保留关系和镜头编号由编译器规范化。支持等价的标签写法及单一源视频目标漏写 Subject 定义的情况；未上传的素材仍不能引用。
- 上传素材是可选来源。未使用的图片、声音既不造成“缺少引用”错误，也不进入 H3 条件输入。选择第二张图片时同步重排模型编号和文件绑定。
- 用户侧中文、模型侧英文；处理控制与正文分开缓存。旧英文编辑稿补做意图解析，同一提示词和素材不重复调用助手。时间、数量和素材标签以占位符保护；“立体”正常翻译成“3D”不再被误判为新增时间数字。
- 纯色背景通过像素检查提供事实，避免把“绿幕”误写成实体 curtain、摄影棚或地板。
- 参考视频按原始时间戳转换到 H3 的 24 fps 时间轴；16 fps 导出在生成后转换，避免直接将 24 fps 动作按 16 fps 播放造成减速。
- 仅在 AI 判定为保持背景、运动的整物表面换样式，且实际视频符合独立、固定位置、椭圆轮廓转至侧面的圆盘条件时，启用旧纹理抑制与位置尺度对齐。人物换衣、局部改色、特效变形不能仅因出现“替换”而触发这些处理。
- 纯色背景恢复使用连续色度键，保留抗锯齿和中性发光；复杂背景、非稳定纯色、低色度背景回退原结果。与背景同色的不透明前景仍是色键方法的边界，不能称为通用视频分割。
