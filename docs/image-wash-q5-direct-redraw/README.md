# Q5 标准重绘验证

目标仍是替换原版 Wan，并同时满足：低强度高保真、高强度增加重绘、画风跟随原图。当前尚未达到，未改软件默认模型。

## 对上一版的纠正

FlowEdit 差分编辑候选已否决。两路几乎相同的源图、目标预测相减，会抵消共同生成变化，因此它的强度参数不能当作普通 img2img 的 denoise。最新 7 步结果仍有半写实光泽、重绘不足，之前“恢复动漫画法”的判断过于宽松。

原版 Wan 使用标准 KSampler 的加噪重绘。新实验恢复这条流程，使用现有 8188 节点，不安装新节点、不启动独立 GPU 进程。此前安装/启动操作被拒绝的路径没有重试。

## 后续验证入口

下一项是保持 7 步、CFG 2、shift 8、0.65 不变，只验证 `medium-first` 提示词。与上一项相比仅改变正面提示；不补跑已否决差分编辑的旧矩阵。需要 8188 正常且队列空闲。应先卸载空闲服务的模型缓存，减少连跑换提示词时的显存残留。
