## 已确认的问题

原工作流的 shift 8 / Beta 将 UI 强度 0.65 对应到约 0.955 的起始 sigma。20 步条件下，改为 shift 1 后为 0.725；0.20 则从 0.531 降至 0.124。这说明此前的低强度并不等同于低噪声，不能将全部画风变化归因于 Q5 量化或模型容量。详见 `sigma-audit.json` 和 `tools/image-wash-sigma-audit.py`。

Qwen2.5-VL 的新提示仍输出过粗描述，且漏掉头发形状和衬衫设计。改用本机已有 Qwen3-VL / NF4 缓存后，真实分析识别出了动漫、波波头、翻领、纽扣和柔和渐变。用时 51.62 秒，完整服务返回保存在 `qwen3-analysis/analysis-response.jsonl`。`profile-with-medium.json` 将该分析中第一个固定字段单独列出，未重新推理或修改其语义；新版服务直接返回这个字段。

媒介负面词只按识别出的明确媒介排除冲突风格。混合媒介及不明确类型不会套用动漫或摄影规则。最后一组 GPU 满负载且耗时波动较大；这里的单次耗时不能作为参数速度的严格对照。

**本轮结论：低强度的 Q5 保真有明确改善；高强度可以输出动漫特征，但尚未保住原图柔和上色与材质表现。增大 CFG 不能单独解决该问题，不把“动漫特征增强”等同于“原图画风一致”。这不证明 Q5 只能写实，也不足以将它作为已经通过的全强度默认方案。**

原版 Wan 与最初 Q5 对照复用既有结果，没有重跑旧实验。当前素材只有一种动漫画风，不能由此宣称各种绘画、照片、像素画都已通过。
