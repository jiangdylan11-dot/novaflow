生成前的 `compileFinal()` 会自动追加角色画质指令，即使没有点击提示词优化，也会加入“只允许局部细弱彩色辅助线”和“受控轮廓光”。AI 助手的二次元预设和 CG 约束中也包含类似内容。

| 输入参考图 | 两个文件名对应的文件字节完全一致 |
| 模型、VAE、采样节点 | 一致，没有调整 |
| 随机种子 | 均为 `773807483` |
| 负向提示词 | 完全一致 |
| 正向提示词 | 用户要求保留，只更换自动追加的画质描述 |
| 其他差异 | 输出文件前缀、输入文件名；输入文件内容未变 |
