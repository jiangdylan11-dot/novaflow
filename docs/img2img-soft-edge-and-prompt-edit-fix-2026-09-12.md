# 黑色描边与提示词局部修改修复

版本：2.3.214。验收对象为普通角色插画及泳装编辑。

安装包大小：249823206 字节；SHA256：`b3f5b4989bcffe2b5867880235ce9cec8e45f40786a56ee5817de0fe71dca1e7`。已从实际安装包解压核对六个关键运行文件与源码逐字节一致，并用包内 Python 服务重新执行实际界面请求，确认成功。安装包沿用项目当前未签名构建方式。

## 查明的问题

1. 生成质量规则仍自动补充“建立清晰轮廓”“有表现力的动作线”。用户反馈的 Rapid 工作流使用 CFG 1，负向中的“粗黑描边”不能提供预期的反向引导。已在本机 ComfyUI `comfy/samplers.py` 核对 CFG 1 条件分支。
2. 风格识别只检查关键词，可能把“不要粗黑描边”当成要求粗线漫画风。
3. AI 助手把非空提示词的局部修改也送入六段结构化重写。实测请求“不要过黑过重的描边”时，模型耗时约 99 秒，返回 `subjects[0].count: 1`，但合同要求字符串，同时存在多个空字段；因此界面报“提示词优化未落实你的修改要求”。不是用户这句话不够具体。

## 最终修改

- 默认角色正向规则改为局部固有色与明暗自然衔接、边缘轻柔细腻、线条纤细轻淡，去掉额外动作线强化。用户明确选择的漫画、赛璐璐和像素风仍保留。
- 风格判断区分明确选择与否定、减弱要求。生成器与助手共享判断函数。
- 本地助手遇到严格识别的纯描边减弱请求时，保留完整底稿并加入明确的正向最终状态，不再要求模型重写整套六段提示词。混合内容修改、资源引用、结构化底稿和冲突风格仍走原编辑流程。
- 保留未修改检测及原有内容保护；正负向通道均可用的接口与只有正向的接口均已测试。
- 精确迁移旧版本自动补充的质量后缀，重复编译不堆叠；用户自行填写的相似文字不被删除。
