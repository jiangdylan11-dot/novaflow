# 万物迁移：场景融合修复（2026-09-12）

目标是将参考物重新绘制成底图的一部分，统一画风、光照、材质表现、透视、清晰度、遮挡、接触关系及投影，而不只是将抠图贴入场景。

## 发现的问题

- 旧回贴使用参考物轮廓加脚下小椭圆，限制了模型实际重绘后的轮廓及长投影。羽化使超出参考轮廓的细节被底图冲淡，造成手部、天线等部位像半透明。
- 原始生成已经包含完整的长投影，但阴影偏蓝、偏重。单纯扩大回贴范围不能解决画风和光照融合。
- 同时保护原图很重要：生成器可能改画原人物，不能直接采用整张模型输出。

## 改动

- 生成时明确底图为唯一视觉标准，参考图仅提供物体身份、造型、关键部件及固有颜色；重新计算物体画风、材质表现、受光、投影、透视和景深。
- 分开处理物体与投影。完整复制允许范围内的生成主体边缘，背景过渡使用羽化，不再用原参考轮廓抹掉重绘后的主体。
- 原图与结果分别提取前景轮廓，保护原有人物和外缘。显式放置物体的主体范围仍允许必要的遮挡。
- 投影使用从接触区域连通出去的地面明暗变化，保留长投影；根据原场景暗部学习色偏与深浅，在原地面 RGB 上施加明暗，保留纹理。
- 阴影远端柔化，脚底接触处保留较清晰的遮蔽关系。

## 实测与边界

使用用户提供的 `a.png`（底图）和 `b.png`（机器人）。位置参照截图设置，不声称精确复用了已被应用重启清理的原任务。对照任务统一 seed 9122026、Rapid v20、6 steps、CFG 1、euler_ancestral / beta。

- 旧提示生成：`3c325025-9c36-4cfd-8671-aacc95a026d8`，约 44 秒。
- 新提示生成：`8b9c2f6c-458b-4972-8c71-ccc488d14712`，约 46 秒。
- 额外前景分析实测约 6 秒（两次）；回贴不再调用扩散模型。
- `after.png` 为新提示及新回贴；`../object-transfer-shadow/before.png` 为旧提示及旧回贴。
- `metrics.json`：原人物保护区域与处理范围外像素变化均为 0；阴影色偏从当前底图估计，不是固定套用蓝色或灰褐色。
- 像素回归、迁移路由、资源加载及补图相关测试：33 项通过。

这是一组实景回归验证。画风/材质是否足够一致仍需要目视验收；复杂透明物体、多个光源、镜面反射、无明显原有阴影或其他绘画风格不应据此宣称已全部通过。底图缺少可用阴影参照时，回贴采用保守的中性色调制。

运行复现脚本：`tools/object-transfer-shadow-live.cjs <底图路径> <参考图路径> --style`。已保存的生成结果会复用，避免重新抽样掩盖回贴差异。
