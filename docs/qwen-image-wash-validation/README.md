## 行为变化

- 原图同时作为 VAE 采样起点和 `TextEncodeQwenImageEditPlus.image1` 视觉参考，正负条件一致。
- 常规小图不再强制放大到约 1 MP；工作图按原图尺寸、16 像素对齐，最多 2,097,152 像素、最长边 3072，以限制 16 GB 显存设备上的开销。输出统一恢复原图尺寸。
- 超过预算的图仍会缩小后处理，恢复输出尺寸不等于恢复所有丢失细节，也不是超分辨率。
- 透明图在模型输入侧铺中性底色，完成后逐像素恢复原始 alpha；低透明度边缘混回源 RGB，减少底色污染。该模式不会扩展原有透明轮廓。
- 重绘强度连续映射：0.10→0.12、0.20→0.185、0.30→0.25、0.60→0.45、1.00→0.75；低/中档 12 步，高档 16 步，CFG 1、Euler/simple。
- 提示词以原图为首要依据，要求匹配原有线条粗细、边缘柔和度、材质与画风；反推文字作为辅助描述，不能覆盖实际图像。
