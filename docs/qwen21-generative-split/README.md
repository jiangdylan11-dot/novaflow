# Qwen Image 2.1 对象分离

已从 `codex/qwen21-generative-split` 接入主线源码。入口位于美工的绘图页，在“拆图”分组的“智能抠图”下方选择“对象分离”。保留原有抠图、去除物体和补图工具。源码与开发运行文件的接入不代表安装程序或线上站点已更新。

## 使用流程

日常只需涂满目标的可见范围，再点击“执行分离”。软件默认自动识别目标、补全遮挡部分、保持原图颜色与质感并修复底图，无需手写这些要求。“对象说明”可留空，只在目标有歧义时写“只要杯子”等简短说明。一个对象可包含多段笔触；多个对象分别点击“添加对象”，最后执行分离。

“特殊要求”默认收起。遇到例外时才展开，填写“对象特殊要求”或“背景特殊要求”，例如保留原有缺口或特定投影。每个已添加的对象保存自己的补充要求；收起该区域会停用本次任务中全部自定义补充，包括已添加对象的补充。普通使用不需要展开。

一次任务共运行 N 加 1 次模型，先修复底图，再逐个提取并补全对象。每一步都引用同一份来源快照，定位参考是在原画面上添加绿色轮廓。得到完整透明对象后，才将底图和全部对象一起置入图层。

原图输入生成新的图层组；图层输入保留来源图层并隐藏它，其他图层保留。支持整次撤销和重做。停止、尺寸异常、非透明输出、来源变化或中途失败均不置入半套结果。

## 模型配置

| 线路 | 主模型 | 采样 |
| --- | --- | --- |
| Turbo BF16 | Qwen-Image-2.1-Turbo-BF16.gguf | Euler 8 步，ManualSigmas，CFG 1 |
| 普通 BF16 | qwen-image-2.1-UC-BF16.gguf | Euler simple 40 步，CFG 1 |

两条线路共用 `qwen3vl_8b_bf16_heretic.safetensors` 和 `qwen_image_2.1_vae_bf16.safetensors`。通过与主线一致的 `NovaFlowGGUFBF16Loader` 读取 BF16 GGUF 原生张量。Turbo 任务调度到 `qwen-image-2.1-turbo`，普通任务调度到 `qwen-image-2.1`。工作流检查计算节点的实际模型列表，缺少指定模型会报错。KV cache 使用 CPU 和默认精度。

## 图像与图层约束

局部区域包含上下文，边长对齐 32，工作图预算为 1048576 像素，完成后还原到原画布坐标。对象补全保留模型输出的 alpha，不通过原笔刷范围裁剪隐藏部位。底图只在选区及扩展过渡边缘写入，其余 RGBA 字节保留；选区核心完全替换，仅外沿羽化，避免混回旧物体残影。

对象完成范围受局部画布和原画布边界限制。自动检查可识别空白、尺寸、透明度和定位重叠问题；不能判断模型是否保留了错误遮挡物。隐藏内容属于推测，复杂人物、细发丝和多重遮挡仍须看图验收。

纯色背景增加原图底色校正：仅当模型生成区域平滑、选区外分布充分的原图参考像素近乎同色时，才匹配该底色。明显纹理、渐变、透明表面或参考不足的区域保留模型结果。这项处理解决平涂底色的色斑，不代表复杂材质已经匹配。
