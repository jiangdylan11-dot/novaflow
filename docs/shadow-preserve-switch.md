# 保留投影开关与轮廓修复

2026-09-13

在抠图处理工具中加入独立的“保留投影”开关，默认开启，状态持久化。关闭后清除能够从幕布暗化和主体遮罩中识别的投影，开启后恢复原始抠图结果。切换不重置“光效透明保留”或其他滑条。

## 本次修复

先前关闭时按投影置信度降低透明度，淡投影外沿因此留下一圈轮廓。现在将置信度用于寻找投影，再清除连通的投影区域，向淡边缘延伸时受主体遮罩和光效颜色信号约束。处理在手绘擦除／修复之前执行，因此笔刷仍能覆盖自动结果。

默认／显式开启保持原结果逐字节不变。人物及薄纱保护区不会因关闭开关而改变透明度。该算法不依赖金色等指定光效颜色，也没有针对素材名称或固定裁切区域的处理分支。

黑幕中无法可靠观测暗投影，此时自动去投影不处理；白幕需有主体遮罩。投影与主体、薄纱或光效重叠时优先保护前景，不能承诺所有未知素材完全自动分离。
