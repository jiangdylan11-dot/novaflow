作者 v4 指南说明，不加风格触发词时默认偏写实。本轮根据源图的动漫媒介加入 smoothmixanime, anime style，没有使用写实触发词。作者的动漫风格仍不等于每一种原图画法。

候选通过 UNETLoader 加载你提供的文件，使用现有 Wan VAE / UMT5 和标准 KSampler。移除了原版额外叠加的加速 LoRA，未使用差分编辑或 I2V 首帧条件。主对照的采样设置沿用旧 Wan，但触发词和 LoRA 有差异，因此不是只换权重的严格单变量实验。

8 步 Euler / Simple 参考作者 T2V v3 示例作为本轮起点；v4 指南未给出新的完整采样参数。所有实际参数、模型路径、prompt ID、运行历史、图像哈希都保存在下方记录中。耗时仅表示本轮观测，缓存与参数不同，不能据此断言比旧 Wan 更快。

本轮覆盖一张普通动漫原图和一个种子；其他画风、其他种子及 NSFW 内容尚未验证。低强度的潜力也不代表已经证明全面兼容。
