# 视频处理操作面板与即时蒙版

2026-09-14

- 上方颜色校正、视频合并、视频抠图只进入工具；工具开启后三个入口全部禁用，保留原名称。
- 三种工具的操作行统一在入口下方分隔线之后，位于该工具内容之前。校正和合并为“确定 / 取消”，抠图为“保存 / 取消”。校正参照上传说明保留。
- 抠图保存走独立的新增资源流程，传入 `activate:false`；不选中新资源，不改变编辑源，也不退出编辑。保存过程中防止重复提交；完成后再次保存创建新文件。旧导出前自动保存并关闭流程保留。
- 取消返回视频处理展开状态。合并确定继续调用原合成并加入资源列表流程。
- 合并默认启用选中视频图层的蒙版编辑，笔触立即进入图层蒙版。切换图层保留蒙版及撤销历史；移除应用、取消编辑、撤销、重做按钮，保留擦除/修复及快捷键。
- 合并的笔刷、羽化和时间线轨道均为 2px；可点击区域仍为 20px。
