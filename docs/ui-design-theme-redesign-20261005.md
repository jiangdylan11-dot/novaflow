# 保布局换主题与仅换画风

用户明确要求“换主题”“主题重设”时，完整参考图只锁定区域位置、占比、网格与功能关系。人物、背景、玩法物品、标题按新主题与明确替换要求重做；金额、规则、控件及状态中未要求改变的内容仍保留。不能把新的主题只做成旧人物和旧符号换材质。

`compileQwenPlan` 使用用户原文决定此范围，优先于误标为 `style-transfer` 的选择器或助手规划。保布局时继续使用 `layoutMode: preserve`，视觉模式为 `theme-redesign`；旧人设/物品身份/原标题的错误保留事实不进入最终指令，几何和功能事实继续保留。原图与风格/素材图的职责、字节与输入顺序继续遵守现有路径。

仅要求“换画风/风格”，以及“不换主题，只换风格”，继续使用 `style-transfer` 并保留未要求替换的原人物、物品身份和文案。这两种需求不能共用无条件的旧内容保留指令。

验证覆盖真实 `prepare → runArtGenerate` 的编译与上传路径，包含助手误规划、缺失规划、主题否定和风格素材角色。此处不调用图像生成；源码与同步运行文件检查不等于正式可见页、实际模型结果、线上部署或费用结算验收。
