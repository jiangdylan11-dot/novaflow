UI 设计质量优化与 GPT 实测结论（2026-10-05）

已找到这张真实布局样例可达标的生成路线，并实际完成本地及 GPT 生成对照。
本地成品独立评审 91/100，GPT 成品 92/100。两者整体处于同一质量档；GPT 的控件材质和体积略好，本地更克制。1 分主观差异不能推论模型普遍优劣。质量第一：采用能提高整体效果的分层，不为分层接受画质退步。

实际解决的根因
1. 让整图模型同时保证精确符号数量、重复资产一致、文字、功能位置和美术质量，前几轮出现改行列、错文字、旧主题残留或照抄风格图内容。
2. Qwen 2.1 具有原生 RGBA 能力。只写绿色背景再抠图不是必需路径。本轮人物、符号和 UI 皮肤直接生成透明通道，未经过 BiRefNet 抠图模型；保留必要的透明数值清理和邻组件碎片删除。
3. 先锁定同一美术方向，再生成完整场景、完整人物与匹配皮肤，最终组合验收。精确文字、同符号复用和结构由程序管理，避免让像素模型反复猜规则。
4. 对完整成品检查，而不是看到单件素材漂亮就通过。实际修复了邻图残片、太小的特殊标牌、加号偏心、人物腰部硬切；噪点底板因画质下降已弃用。

对照条件
4 个资产任务（背景、符号、人物、控件）的提示词和参考文件字节一致，使用相同最终组合规则与 758×1640 画布。参考中包含先前本地产出的美术锚点，因此这是“美术方向确定后的资产供应与组合效果”比较，不是从零独立创意盲测。
原始分辨率并非全部相同：本地背景 758×1640、人物768×896；GPT 背景1024×2208、人物1024×1200；符号1024×1024、控件1024×1536相同。不能把这轮视为完全相同像素预算的模型排名。
本地当前实测模型为 qwen-image-2.1-UC-Q8_0.gguf，编码器qwen3vl_8b_w4a8_heretic.safetensors，VAE qwen_image_2.1_vae_bf16.safetensors；40 步、CFG1、Euler/simple。本轮优化的是生成与组合路线，未训练或替换模型权重。
GPT 经正式产品适配器 OpenAIGPTImageNodeV2 实际调用，提供方返回别名 gpt-image-2.5-sunburst；此别名不能独立认证官方模型版本。不是仅预检，也不是之前的 imagegen 风格参考。
GPT 四项 result 记录总时长182.438秒；本地对应四项约388.922秒。仅一次机器和网络条件下的观察，不承诺固定加速。GPT提供方旧通道返回约68.83 credits，含舍入；不是已核对的正式 Web 账单或最终结算金额。

可编辑交付
每版78个图层，包含完整背景、完整人物、符号玻璃区、4奖池、购买按钮、说明框、金额栏、加减按钮、5底部控件、30符号实例及独立文字/图形。
design.psd / design.ora、独立透明 PNG、原始 PNG、文字 JSON 和离线 HTML 编辑预览均已提供。图层可独立移动/隐藏，移开人物后背景完整，人物躯干并没有因符号框而被永久裁掉。
PSD 的文字是栅格层，text.json保留文字信息；不能冒称 Photoshop 原生可编辑文字层。PSD 严格读回78层的RGBA与坐标；独立 Pillow 实际读开PSD，合成图与预览逐像素一致。实际 Photoshop 界面未打开验收。

产品落地路线
第一步：保留“布局图＋风格图＋人物/物品素材＋简短需求”的单次生成体验，内部确定布局语义、主题与统一美术锚点。
第二步：以整体质量决定输出。能一次整图达到更好质量就保留整图；需要精确重复资产、文字或后期编辑时，在同一方向下采用原生透明资产与确定排版。
第三步：生成完整被遮挡背景/人物，语义分层独立保存；不要拿整个格子矩形当抠图 mask，更不要通过不完整裁切假装可编辑图层。
第四步：整张成品验收过关后导出，未过关定位到背景、人物、资产、组件或文字的实际缺陷并继续修；重新组合仍需看实际成品。
第五步：用至少三张不同的真实完整 UI 与不同种子复测，检查布局保持、换主题、部分修改和图层编辑。模型切换复用同一合同，按成品质量选本地/GPT。

当前完成范围及后续边界
这一轮已完成一个历史真实布局样例的可用成品、两种模型实测、透明通道验收、分层交付及编辑预览；通用格子验证器从83个实测框恢复6×5的28/30格，并拒绝跨分区伪阵列，另测4×3及2×7。两个漏测框、本张符号语义及风格取样仍由人工核对，不能宣称全自动任意UI已成熟。
正式产品源码已支持 GPT 的 auto/opaque/transparent 背景参数，默认行为保持auto；已同步运行文件，并通过现有22项适配器检查、真实源码14参数检查、runtime与entry检查。
完整分层生成路线当前是可复现隔离原型，尚未接到正式单按钮，也未部署线上或更新安装包。后续接入必须保留当前简洁入口，补自动语义/透明资产质量验收及跨样例回归；不能把本轮单样例打分当成正式产品终验。
游戏说明文字是明确的测试补全，不是已确认的原图全文或玩法规则；商业交付应以用户完整原文替换。
