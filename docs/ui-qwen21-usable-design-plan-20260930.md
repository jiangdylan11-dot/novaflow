# Qwen 2.1 UI 原生编辑方案（修正方向）

用户操作保持现有界面：添加参考图、输入简短设计需求、开始生成。左侧布局编辑是可选扩展，不增加模板、模式选择、手动优化或验收弹窗。GPT/Google 生图本次不改。

## 正式路线

Qwen 2.1 直接编辑完整参考图，生成完整 UI。布局是参考图中的空间、比例、衔接和叠放关系，不是把区域拆成独立素材后铺进矩形格子。

- 没有自建布局：用户指定的布局参考或完整 UI 图直接进入编辑输入。未提出改变布局时，沿用原图；换主题改变人物、场景、符号和组件美术，不代表重新排版。
- 有自建布局：开始生成时自动从布局器的当前坐标生成布局参考图，更新旧导出图或加入生成快照。无需先点击“生成布局参考”。布局器优先，风格图不能取代它的排版。
- 风格图提供配色、材质、笔触、体积、光照和设计语言。人物/物品图提供身份；布局图提供空间关系。只有风格或素材图时，允许自动设计布局。
- 用户要求局部调整时，仅修改指定位置、大小或数量，其余区域保留。自建定位图中的灰块不是成品形状或内容，不保留占位框，也不把模块名称当文案。

后台分析只将用户要求和参考职责编译为清楚的原生编辑指令，不能替代参考图。生成不再依赖两次阵列清点一致；参考图片直接提供原布局，不将视觉模型猜测的行列数编译成格子模板。用户或布局器明确指定的位置、数量和改动仍保留，不逐个生成符号、不程序拼装成品。

## 已撤回的试验

“拆背景、人物、控件、符号 → 分别生图和抠图 → 确定坐标拼装”的试验已从正式入口、工作流注册、后台及 Python 调用中移出。试验源码与实际图片保存在忽略目录 `.artifacts/abandoned-ui-composition/` 和 `.artifacts/ui-composition-20260930/`，不发布到网页或助手。

撤回原因：模型分组不稳定、像素分割容易漏人物或文字、控件不一定等宽等高；强制逐格拼装会损失参考图的叠放、异形轮廓和整体质感。单张拼图通过视觉检查不能证明这条路线广泛可用。

## 本次代码修正

- 当前布局自动进入生成参考图快照，替换过时导出而不修改用户原始图片和编号。参考图上限按实际生成模型检查，超限不偷偷截断。
- 自建布局图必须成为规划的布局来源，不能被另一张完整 UI 或风格图覆盖。
- 原生编辑说明区分“现有 UI 画布”和“自建空间定位图”，不让模型保留灰块与占位框。
- Qwen 2.1 UI 请求遇到无法构建的节点明确报错，不回落到其他模型。
- 执行桥保留用户采样设置与 LoRA 数据；绘图与云端流程保持原入口。

## 验收与限制

代码回归和运行文件同步不能替代真实成品验收。整图原生编辑能保留整体美术关系，但仍可能出现区域比例、符号行列或文字偏移；不能承诺逐像素锁定或已达到商业质量。

此前真实 Qwen 2.1 测试中，部分结果的材质与色彩改善，但太空、海盗、纯风格迁移等案例仍有布局或内容问题。结果记录在 `.artifacts/ui-qwen-native-20260930/` 等忽略目录，不能算完成验收。本次修正方向后，应继续验证参考图迁移、自建布局、局部调整和不同 UI 类型，而不把旧拼装样例当作新路线的成品。

本次仅更新源码与开发运行文件。未更新已安装助手、后台线上服务或发布包，未打包、推送或部署。

本次验证：27 项 UI/运输回归通过；213 项 Qwen 页面规划与 Worker 图检查通过；运行目录和入口检查通过。真实 Chrome 中挂载布局编辑模块、添加并移动布局块，在未导出参考图时调用正式 prepare，生成快照自动包含当前布局图，移动后的图像和坐标均更新；该测试的规划接口使用测试替身，不属于真实模型效果验收。没有使用旧拼装成品证明新路线的质量。

后续修正：移除原生生成前的行列计数一致性门槛及重复数字约束；原图直接提供布局。原生 UI 保持或局部调整布局时，改变输出分辨率仍使用完整参考图的编辑输入，禁用裁剪，不会静默切成空白布局生成；明确重排和绘图原流程保留。

真实样例对比：原图和另一张完整 UI 风格图同时作为 Qwen 原生图像输入时，太空主题人物覆盖了符号区；因此有布局来源时，风格图由视觉规划读取，提取其材质、配色、光照与体积描述，原生编辑仅以布局图作为空间输入。这是实测后的取舍，风格仍需逐主题验收，不能保证完全复制参考图的美术细节。

2026-09-30 实际 Qwen 2.1 输出验收（开发测试，非用户生产发布）：`native-v7/space` 顶部四个奖池、人物区及底部操作栏仍在，材质和主题已改变，但符号区比原图多一行，原三叉戟造型仍被带入；`native-v7/partial` 人物明显缩小、顶部与底部保留，符号区同样多一行。两张完整参考图同时进入原生编辑的 `native-v6/space`，人物甚至压入符号区，纯风格迁移的 `native-v6/style` 复制了埃及图案和网格线。因此当前路线只能证明部分布局和美术变化有效，不能宣称已稳定达到“保持布局同时全主题重做”的可用验收。真实 PNG 与执行图、历史保存在忽略目录 `.artifacts/ui-qwen-native-v7-20260930/`；仍需解决模型对重复行列和旧道具的保留偏差。

补充反证：在相同原图、种子和模型图上，手动追加“符号矩阵准确为六列五行，不增加第六行”，得到的 `space/grid-fact-probe.png` 依然是六行。因此数字提示不能单独解决布局保真，不将该试验纳入正式生成，也不恢复会阻止生成的双重计数门槛。Qwen 图像输入是参考条件，原生节点返回空 latent，不具备逐像素锁定能力；严格布局尚需另外的结构控制和真实样例验收。
