# UI 设计实施记录（2026-09-30 修正）

## UI 输入区域简化（2026-09-30）

- UI 正向提示词标题改为「设计需求」，本地负向标题改为「避免内容」，并显示可选填写的占位说明。两个标题均为静态文字，移除提示词历史入口。保留编辑按钮，编辑弹窗使用相同标题。
- UI 不再挂载手动 AI 助手按钮；开始生成前的自动需求理解、缓存与布局融合保留。绘图页的助手和历史功能保持原样。
- UI 不显示 NSFW 开关，生成快照固定 nsfw=false。模型容量、采样参数和兼容 LoRA 目录使用普通 Qwen-Image 2.1 路径，原绘图 NSFW 状态保留，切回绘图恢复显示。
- 提示词框按 UI／绘图区分保留策略，防止切换时把旧标题或助手按钮迁入新页面；绘图历史弹层切到 UI 后关闭。
- 验证：相关回归测试共 54 项通过；sync:runtime、check:runtime 与 check:entry（273 项断言）通过。4892 实际页面确认本地双标题、GPT 单标题、编辑弹窗标题以及绘图／UI 切换后的控件恢复。当前无可用算力节点，未验证实际出图；未发布线上站点或更新已安装助手。

## 参考图容量修正（2026-09-30）

- 绘图与 UI 共用生成模型容量：GPT 16 张、Google 14 张、Qwen-Image 2.1 10 张；本地 NSFW 的旧 Qwen 编辑节点仍是 3 张。已核对本机 ComfyUI 的 OpenAIGPTImageNodeV2 16 个输入与 GeminiImage2Node 的 14 张校验，不沿用前端旧的统一 3 张默认值。
- 助手分析与生成容量分开：UI 助手不再额外限制云端 4 张、本地 3 张；绘图助手、后台云端解析、启动助手和 Python 服务不再截断图片列表。无效图片明确报错。视觉分析仍受实际请求大小、上下文及本机显存约束，不保证任意数量或尺寸都能成功。
- 云端分析副本按总计 6 MiB 二进制预算分配压缩容量，为后台 10 MiB JSON 上限中的 Base64 和文字留空间；不修改生成原图。压缩无法达标时明确提示，不丢图。
- 模型切换保留并显示超额参考图，允许逐张删除；超限生成在上传前拒绝，不再只取前几张。界面排版及其他功能不变。
- 验证：生成工作流 16/14 张及超限、助手 16 张顺序传递、总容量、切换保留、UI 折叠/首帧等回归通过；Python 图片入口测试通过；同步、运行检查与入口检查通过（入口 273 项断言）。浏览器确认 GPT 16 / Google 14 / 本地 10 的上传提示，以及 UI 共用入口。浏览器实际导入因扩展未允许文件 URL 访问而未完成；未调用真实模型。开发运行文件已同步，未打包、未部署线上或覆盖已安装助手。

## 当前界面约束

以用户图 2 的实际图生图界面为准。UI 入口直接复用绘图的侧栏、画板、原图/图层切换、缩放、资源栏、生成参数、参考图、正负提示词、历史和编辑器，只在左侧新增「布局编辑」。此前单独实现的工作台壳层已退出正式入口。

后续范围修正：复用排版不代表迁入绘图的全部功能。UI 侧栏只保留「生图」和「布局编辑」，不渲染「编辑、拆图、增强」三个分组，也不显示「文生图／图生图」模式切换；内部根据参考图自动选择生成路径。绘图页仍保留原有分组和模式切换。已在真实源码页面验证 UI → 绘图 → UI 切换及布局展开；运行同步、运行检查、入口检查和 6 项 UI 生成回归通过。未发布线上。

### 切换、首帧和折叠故障修复

- UI 的挂载判断改为检查自己的生图分组。此前仍要求存在绘图的编辑、拆图分组，导致重复卸载和重建，丢失按钮状态。
- 绘图与 UI 的侧栏在下一次绘制前完成交接，保留共享画板、资源栏；过时的切换回调不再执行。重复点击当前标签直接忽略，不重建页面。
- 资源栏容器排除生成浮层及其后代，避免快速切换时错误嵌套、持续偏移和遮挡。UI 扩展等共享画板就绪再开启生成区。
- 生图同步不再关闭独立布局编辑器。UI 侧栏不挂载旧的内嵌账号视图；切回绘图恢复其原行为，授权与登录校验未变。
- 真实源码页验证：两侧切换、绘图四分组及 UI 两分组展开/收起、生图到编辑的切换、布局展开后重复点 UI、快速往返六次。未修改页面排版。
- `ui-design-transition-preview.mjs` 直接提供实际 renderer，只附加 DOM 帧采样，无界面、账号或模型替身。绘图收起→UI、UI→绘图、绘图生图展开→UI 三种场景，首帧至第 12 帧的分组、画板、生成区和资源栏坐标一致，挂载宿主替换次数为 0；快速往返后的最终 UI 同样稳定。截图和原始采样保存在本次 Codex visualizations 目录。
- 7 项生命周期回归、6 项 UI 生成回归及 `check:entry` 通过，`sync:runtime`、`check:runtime` 通过。源码与开发运行文件已更新，未发布线上或更新已安装程序；本轮未验证真实模型出图。

布局编辑默认收起；展开后在原画板区域编辑模块，左侧编辑当前模块的名称、位置、尺寸、作用和要求。支持拖动、调整尺寸和删除；移除侧栏撤销、重做按钮，“+ 布局块”铺满整行。删除按钮使用深灰底和描边，悬停或键盘聚焦时以浅红文字提示删除。没有额外的侧栏小预览或模块列表。生成布局后加入图生图原有参考栏；关闭布局编辑返回原画板。

### 2026-09-30 布局分辨率联动

- UI 的有效 W/H 输入立即同步布局画板、尺寸标识、模块坐标和已添加的布局参考；输入中的不完整数值不压缩画板，提交时仍沿用绘图的范围校正。
- 更新布局参考时只刷新参考图区域，保留宽高输入框及 Tab 焦点；普通绘图输入行为保持原样。
- 同步升级相关入口脚本版本，避免浏览器继续使用修复前的账号框、切换逻辑和按钮样式。
- 实际源码页面验证：1280×720 画板和参考图同步、连续输入不中断、Tab 从 W 进入 H、模块尺寸同比缩放；满宽添加按钮和深灰删除按钮截图已留存。21 项相关回归、运行同步检查和入口检查通过。尚未发布线上。

## 生成接入

- 移除模块属性中的“参与生成”和“锁定布局块”。所有画板模块统一可编辑、拖动、缩放、删除并纳入布局参考；打开或更新旧项目时清除历史锁定及排除状态，旧参考的说明也不再按参与标记过滤。未添加布局参考时仍不强制使用布局。
- 本次实际页面验证两个勾选项消失、拖动坐标回写、新增及删除、生成布局参考正常；15 项相关回归与运行、入口检查通过。源码和开发运行文件已更新，未发布线上。

- 模块属性中的“作用说明”和“生成要求”已合并为“模块说明”。旧数据两段文字合并显示；编辑后写回统一说明并清空旧要求，避免残留或重复。
- 模块名称仅供编辑器识别。创建布局参考、提示词优化和最终生成均只使用模块说明及位置尺寸；读取旧布局参考时同样剔除名称、标题和标签，保留项目内原名称。
- 本次实际页面验证单一说明框、名称和说明编辑、生成布局参考；14 项相关回归验证旧说明兼容及模型请求不含模块名，运行同步、运行检查和入口检查通过。未调用真实模型出图或发布线上。

- UI 使用真实绘图生成入口 `runArtGenerate`，先运行 UI 专用需求优化，再调用既有图生图执行链。普通绘图不进入 UI 优化。
- 原始提示词保留；相同输入复用优化结果，失败或取消不提交生成。
- 布局是可选参考图。不使用布局也能生成；无任何参考图时使用文字生成路径。
- 步数、CFG、LoRA、种子、尺寸、云端选项和数量使用现有绘图参数；优化开始时快照参数，避免处理过程中改参数影响本次任务。
- 布局参考附带模块功能及坐标，更新同一张参考图。参考图有空位时将用户引用映射到实际上传顺序；无效引用及超限明确报错。
- UI 与绘图共享现有画板、资源和生成控件。旧 UI 布局项目存储保留，生成结果进入共享资源流程。
