# UI 工作台改版实施记录

## 已接入源码

- UI 入口使用绘图式工作台：中央画板、底部生成参数和参考图、右侧原有资源区。节点图保留为旧项目的存储兼容层，不再要求用户连接节点。
- 左侧结构生成器可展开；支持添加模块、画板拖动和缩放、单模块属性、撤销重做。没有模块列表或侧栏小布局预览。
- 布局参考按同一份数据更新；移除参考保留草稿，删空布局解除结构输入。更改输出尺寸按比例映射模块坐标。
- 纯文字、只有参考图、自建结构均可进入生成。没有结构时不上传虚构的布局控制图；云端模型的纯文字路径沿用界面所选质量和比例。
- 本地正负提示词并排，GPT / Google 不展示无效负面输入。结果可以加入参考或设为继续修改的底图。
- 精简 AI 助手，去掉设计动作、固定风格、内容分类和质量倾向；保留必要的处理服务选择和补充需求。
- 一次点击串联需求优化与生成；原始输入保留，上次生成指令可查看。相同输入复用优化，输入改变重新优化；取消和失败不进入下一阶段。
- UI 专用云端和本地提示词规则保留目标界面按钮、菜单及指定文案，与绘图任务分开处理。

## 已验证

- `web-ui-design-qwen21.test.mjs`：185 项断言通过，包含本地 / GPT / Google 的无布局、无参考、编号映射和参数保留。模型与网络调用为测试替身。
- 工作台、提示词控件与助手对话框：18 项行为测试通过，包含优化复用与失效、取消、参考编号、云端 UI / 绘图分支隔离、布局编辑及恢复。
- `check:entry`：4 个测试文件通过，内部共 271 项断言，覆盖助手、启动器、提示词服务接入和网页算力路由。
- 浏览器中的真实组件验收：结构展开、模块创建及命名、拖动回写坐标、布局参考启用、双栏提示词、精简助手、手动优化复用、生成结果入库。生成服务使用测试替身，页面明确标注测试环境。
- JavaScript / Python 语法检查通过；开发运行文件已通过 `sync:runtime` 同步，`check:runtime` 检查通过。

组件验收页可通过 `node novaflow-web/tests/e2e/ui-workbench-preview.mjs` 启动，仅监听 `127.0.0.1:4894`，不访问真实模型或账号服务。
