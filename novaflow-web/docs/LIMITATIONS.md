## 生产环境没有动过

**数据库迁移没有执行。Edge Function 没有部署。Web 站点没有上线。**

构建机上没有 service-role key、没有数据库密码、没有登录过的 Supabase CLI、
没有任何托管商账号。而且规则本身就要求不得自动对生产库做迁移。

迁移 SQL 在**真 PostgreSQL**（PGlite，跑的是同一批既有生产迁移）上验证过：
能应用、可重复应用、纯增量、可回滚。但你的生产库现在仍然是原样。
执行步骤见 [DEPLOY.md](DEPLOY.md)。

同理，**没有用真实生产账号登录过**。登录走的是现有后端，代码一行没改，
令牌格式逐字节兼容，但「真账号真登录」这一步需要你来做。

## Web UI 的功能范围

Web 版复刻了 NovaFlow 的外壳：同样的深色配色、同样的 56px 顶栏 + 80px 主轨 +
242px 面板布局、同样的四个分区（特效 / 动画 / 美工 / 工具）、同样的
仓库 / 导出 快捷入口、同样的 `#1ea672` 主色。所有设计令牌是从稳定版
`novaflow-brand-runtime.js`（HEAD `f5b31cf`）里**读出来的**，不是照着截图配的，
集中放在 `web/src/theme.ts`。

但**功能只接了走 GPU 的那几条**：绘图、图生图、AI序列。

没接的入口在界面上**是可见但禁用的**，鼠标悬停会说明原因：

| 入口 | 状态 | 原因 |
| --- | --- | --- |
| 粒子特效 | 禁用 | 本地编辑器功能，不依赖远程 GPU |
| AI特效 | 禁用 | 需要 AI特效 工作流，本次未接 |
| 骨骼动画 | 禁用 | 本地编辑器功能（自动蒙皮 / 骨骼编辑器 / 权重编辑器） |
| UI | 禁用 | 本次未接 |
| 实用工具 | 禁用 | 本地编辑器功能 |
| 仓库 | 禁用 | Web 版未提供 |

为什么这么划：稳定版渲染层是 58 MB、96 个运行时补丁模块的 Electron 产物，
大量逻辑绑在 Electron IPC、本机文件系统和本机 ComfyUI 上。逐字节搬到浏览器
既不现实，也会把一堆没有 Web 对应物的路径拖进来。Web 产品线的意义是
「用远程 GPU 跑生成」，所以先把生成这条线做完整，本地编辑能力留在 Desktop。

禁用而不是隐藏，是为了让缺口是**明说的**，而不是看起来像不存在。

## 工作流只验证了一条

| task_type | 状态 |
| --- | --- |
| `qwen_t2i` | ✅ 在真 ComfyUI 上端到端跑通，多次 |
| `qwen2511_edit` | ⚠️ 图是合法 ComfyUI API 格式、绑定全部可解析，但**没跑过真实生成** |
| `h3_i2v` | ⚠️ 图按 8189 运行时 `/object_info` 的真实节点签名构造，结构照搬稳定版 H3 管线，但**没跑过真实生成** |

H3 那条没跑，是因为一次视频生成要占用这台机器的 GPU 很久，而端到端链路
（调度 / 传输 / Range / 结算 / 清理）已经由图像任务完整证明了——视频只是换一张图。
第一次真跑 H3 时，如果你的 H3 装机与参考 rig 不同（LoRA、加速节点、
`CLIPLoader` 的 `type`），可能需要微调 `worker/workflows/h3_i2v.json`。

## 网络

**只实现了 direct。** Worker 的网关端口必须让浏览器能访问到：
同局域网填内网 IP，有公网 IP 就做端口转发。

没有公网 IP 的机器，目前要自己套隧道（cloudflared / frp / tailscale），
把隧道 URL 填进 `NOVAFLOW_PUBLIC_ENDPOINT`。

数据模型已经是传输无关的：`gpu_workers.transport` 有 `direct` / `tunnel` 两种取值，
`endpoint_url` 只是普通字符串，任务系统、文件系统、Worker 身份都不绑定固定 IP。
所以加内建隧道是加一个实现，不是改架构。但**这个实现本次没写**。

---

## Worker 网关是明文 HTTP

浏览器到 Worker 之间没有 TLS。凭证本身是 HMAC 签名的、短期的、单任务单操作的，
但传输内容（参考图、生成结果）在链路上是明文。

局域网或可信网络里可以接受。放到公网建议在 Worker 前面套一层带 TLS 的反向代理
或隧道（隧道方案通常自带 TLS）。

另外：从 HTTPS 页面 fetch 明文 HTTP 的 Worker 会被浏览器的混合内容策略拦下。
所以 Web 站点上了 HTTPS 之后，Worker 端也必须有 TLS——这是上公网前必须解决的一项。

## 模型管理

**做了**：清单、检测、能力上报、按 ready 调度、大小校验、缺失/损坏区分。

**没做**：自动下载。清单里 `download.mode` 是 `import_or_configured_url`，
因为这些权重是按用户授权的，本项目不适合代为分发。Worker 的做法是指向一个
已有的 ComfyUI models 目录。

**没有 pin 哈希**：`required_files[].sha256` 全是 `null`，所以只校验存在性和大小。
报告里会如实写成 `size_only_no_hash_pinned`，不会假装校验过。
要开启哈希校验，把真实 sha256 填进清单即可，代码路径已经在了。

## Web 端没有授权门槛

桌面版用授权文件锁 仓库 和 导出，而授权文件是**绑定机器码**的。
浏览器没有机器码，也就没有东西可绑、没有文件可签发——照搬过来只会得到一个
永远填不成功的表单。所以 Web 端一律报「已授权」，仓库和导出直接可用。

这不是绕过桌面版的授权：Web 上真正花钱的是**生成**，每一次生成都带着会话令牌，
由控制面校验并扣积分。导出和仓库动的是用户自己浏览器里的画板，不该拿机器授权挡。

登录仍然存在，但它管的是积分和提示词服务次数，入口在
**动画 → AI序列动画 → 模式选择 → NovaFlow 账号**（桌面版原本就在那儿），
打的是现有的 `novaflow-backend`。

## 桌面专属的控件：藏了，不是删了

Web 版顶栏隐藏了两处只有 Electron 才讲得通的东西：

- **最小化 / 最大化 / 关闭** —— 浏览器标签页自己就在上面有这三个，
  而且其中两个在页面里根本做不到。
- **释放内存** —— 桌面版释放的是本机 ComfyUI 的显存。Web 上显存在**别人的机器**上，
  用户既没理由也没办法去卸载它。按下去只能清掉本标签页的缓存，却让人以为动了显卡。

底下的方法都还在，也都如实回答（`runtimeFreeMemory` 返回 `freed: false` 并说明
显存在算力节点上），因为渲染器还会从快捷键或状态刷新里调它们。
判据是：**做不到的事就不要摆一个按钮说能做**。

## 其它没做的

- **速率限制**：控制面没有限流。现有 `novaflow-backend` 对 license 校验有限流
  （`check_novaflow_license_verify_rate_limit`），Web 控制面没有等价物。
- **Worker 自动更新**：规格里提到「自动更新能力」。安装包能覆盖安装，
  但没有做自动检查更新 / 静默升级。
- **Worker 代码签名**：安装包未签名，Windows SmartScreen 会提示。
- **结果内容审核**：不做任何生成内容的检查。
- **多 GPU**：一台机器多张卡时只识别第一张，且一次只跑一个任务。
- **任务优先级 / 配额**：FIFO，没有优先级，没有按用户限流。
- **Worker 端 i18n**：界面是中文的。
- **移动端**：外壳按桌面级画布设计（和 Desktop 一致）。窄屏下能用不会错位，
  但没有做手机版布局。

## 一个被接受的取舍

任务跑完但**结算失败**时（例如积分 RPC 临时不可用），任务仍然标记为
`completed`，用户能看到结果，而结算失败被记进日志、任务的
`credit_settled` 留在 `false`。

也就是说：这种情况下可能漏收一次费。选这个方向是因为反过来更糟——
收了钱却让用户拿不到结果是不可逆的，漏收一次可以事后对账补上。
`web_ai_tasks.credit_settled = false` 且 `status = 'completed'` 就是对账的查询条件。
