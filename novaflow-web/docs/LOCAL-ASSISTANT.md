# 统一浏览器工作台与本地助手（第一阶段）

## 使用方式

同一份 `web-dist` 同时供线上 WEB 和本地助手使用。本地助手默认提供
`http://127.0.0.1:4784/`，与既有 4783 预览入口分开，避免占用正在运行的测试端。
这不是另一套编辑器源码；本地只注入连接配置，工作流构建仍由 Worker 执行。

底部只有两个操作按钮，下面分别放置「快捷打开本地界面」「快捷打开外网界面」链接：

1. **启动NovaFlow / 关闭NovaFlow**：先检查本机授权。未绑定或授权失效时，在助手内显示机器码授权遮罩层，
   支持重新验证、导入 license.nfl 和粘贴授权码，沿用原授权字段与校验规则。
   授权成功只关闭弹层并提示成功；用户再次点击「启动NovaFlow」才启动运行环境、工作台并打开浏览器。
   点击「关闭NovaFlow」立即取消本机正在执行和排队的任务，并关闭工作台，不停止分享。浏览器收到关闭通知后尝试关闭标签页；
   浏览器不允许脚本关闭时，显示「NovaFlow 已关闭」页面。
2. **开启算力分享 / 停止算力分享**：无需先启动本地端，也不要求本地编辑器机器授权；
   仍按原节点注册规则接入，首次接入可在设置页填写注册码。分享不会打开本地工作台。
   停止分享不关闭本地端；立即取消已接共享任务，迟到的领取响应也不能执行；已完成结果的文件网关保留供下载。
3. 两者共用图像/H3 运行环境，只有两者都停止且取消清理完成，才停止助手自己启动的环境。
   先前已运行的环境继续复用。未安装运行环境或节点注册失败时会报告实际错误。
4. 助手默认宽 680、最小宽 620；授权卡片宽不超过 520，在同一个窗口内居中显示并遮罩底层操作。
   不再创建额外授权窗口。设置页查看绑定使用同一遮罩层。
5. 本地链接仅在工作台启动后可用；浏览器意外关闭后可重新打开配对界面，不重复启动服务。
   本地与线上入口均要求账号登录，已有有效账号会话仍可复用。
6. 算力按钮使用黄色；启动显示阶段进度、具体步骤与已用时间，同时操作显示排队等待。进度按步骤推进，不估算加载百分比。
7. 外网链接固定打开 https://novaflow.jiangdylan11.workers.dev/ ，无需启动任何本地服务。

本机入口始终连接本机队列，线上入口始终连接云端；编辑器没有算力切换或节点绑定按钮。
本机授权仍读取 `%APPDATA%/NovaFlow`，提交本机任务时服务端再次验证授权。

分享每次启动都默认关闭；既有 headless Worker 入口仍按原行为提供共享算力。
助手只关闭自己启动的运行环境，不停止启动前已经存在的客户端运行环境。
本机/共享任务由同一个执行循环串行执行；当前共享任务完成后优先处理本机队列。
编辑器没有运行中切换入口，本机连接失败时不会自动将任务转交云端。

## 开发入口

```powershell
npm --prefix novaflow-web run build:renderer
npm --prefix novaflow-web run assistant:start
```

CLI 会生成本机「打开 NovaFlow.url」快捷方式，使用它完成浏览器配对。
直接输入 URL 可以查看界面，但没有配对凭证无法操作本机队列。
`NOVAFLOW_ASSISTANT_DATA_DIR` 可指定隔离数据目录，`NOVAFLOW_ASSISTANT_PORT`
可指定 CLI 工作台端口；Electron 通过设置页配置端口。

助手运行目录构建：

```powershell
npm --prefix novaflow-web run build:renderer
npm --prefix novaflow-web/worker run build:win:dir
```

正式安装包仍用 `npm --prefix novaflow-web run worker:build`。
产物内含统一 WEB、工作流执行模块和原授权校验模块，不包含模型权重。

## 验证与当前边界

- `local-assistant`：真实 HTTP 私有队列、文件凭证、分享失败不影响本机、停止分享善后、
  本机任务优先、运行中取消、私有与共享文件隔离。ComfyUI 使用明确的测试服务。
- `web-compute-mode`：浏览器适配器不把本机任务回退到云端，不向云端发送配对密钥，
  本机/云端入口路由固定、账号请求仍走账号服务。
- `worker-account-binding`：实际 PGlite 控制面验证账号自绑定、维护状态、不允许换绑、
  重启保留归属；账号会话令牌不保存到节点身份文件。
- `local-assistant-live.test.mjs`：可选真实 ComfyUI GPU 测试。明确使用隔离的测试授权夹具，
  不修改本机原授权、不证明正式账号授权成功。2026-09-22 实际生成并下载保存 512×512 PNG，
  任务 `c32647b8-713c-460c-888a-cc531cb91c51`，结果 236960 字节。
- `worker-start-retry`：节点注册失败后释放资源并可重试。
- `local-launcher`：执行真实主进程 IPC，Electron、授权和运行环境使用隔离测试替身；
  覆盖直接分享、两个开关独立、绑定成功不自动启动、第二次点击打开、错误重试、固定外网链接与单窗口。
- `local-assistant` 另验证未授权机器从全新助手直接分享、本地启动拒绝不影响分享、
  关闭本地不打断共享任务、停止分享善后与浏览器关闭通知。
- 浏览器交互验证使用真实助手 HTML 和真实主进程 IPC 的隔离测试入口，确认按钮切换、
  授权成功后等待再次点击、620×690 可用区域内的居中遮罩。未操作真实授权或生产分享。
- 可用 `node novaflow-web/tests/helpers/preview-launcher.mjs` 启动隔离交互预览，测试授权输入为
  `test-only-license`；此夹具仅存在于 tests，构建不包含测试入口，不改变正式授权规则。

## 2026-09-22 启动反馈、快捷链接与立即停止修正

- 本次真实本机已由用户完成授权。原生日志复现冷启动耗时 154.6 秒：视频启动脚本的父进程已经退出，但 `execFile` 仍等继承到 Python 的输出管道关闭，恰好等待 150 秒超时。改为无继承管道的 `spawn` 并监听启动进程退出；运行环境就绪探测仍保留。相同机器实测冷启动到打开浏览器约 25.4 秒，不代表所有电脑固定用时。
- 两个启动操作均通过真实 IPC 显示步骤进度与时间，排队操作显示等待；失败不会显示 100%。黄色分享按钮和两列快捷链接已在当前原生窗口核对。本地标签关闭后点击左侧快捷链接，Chrome 创建新 4784 标签并显示登录页；未输入用户账号密码。
