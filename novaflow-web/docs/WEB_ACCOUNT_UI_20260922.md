## 行为

- 账户使用原生模态 dialog，顶部栏和左侧一级导航均处于遮罩下面，弹框打开时背景不可交互。
- 显示账户名称、可用积分和提示词服务的剩余次数 / 总次数。
- 每次打开通过现有账户服务 `/api/client/bootstrap` 读取余额和 `providerQuotas.grok`，不从算力接口推断提示词配额。
- 读取失败显示未读取状态及「重新读取」，不伪装为零次；保留右上角叉号、Escape、点击空白关闭与焦点恢复。
