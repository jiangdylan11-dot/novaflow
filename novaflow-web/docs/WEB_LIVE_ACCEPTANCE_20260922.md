- 模型可用性按实际任务使用的图像或视频服务分别判断，图像服务看到 H3 权重不再使已停止的视频服务被报为可用。

- 不自动启动任意用户配置的算力服务。本机本次已用现有脚本恢复服务；重启电脑后仍需要启动相应算力服务。
