# Web 本地仓库映射

## 原因与修改

正式网页的仓库快捷入口调用 `runtimeOpenOutputFolder`，但 Web runtime 与 capabilities 都只返回“不支持本地目录”；入口未呈现该错误，造成点击无反应。

新增浏览器专用 `novaflow-web-warehouse.js`，并通过现有快捷入口打开仓库面板。该模块只进入网页，不进入算力节点。无需更新 Worker 或云端函数。

- 首次在“仓库 → 连接 / 更换文件夹”选择本机目录并授予读写权限。
- 生成输出下载成功后，图片和视频进入同一个本地保存队列；参考图、输入遮罩不在此入口入库。
- 未连接目录或权限失效时，结果暂存于当前浏览器的 IndexedDB，面板显示待保存数量；恢复授权后重试。若浏览器暂存失败会提示保持页面打开。
- 文件夹映射保存在同一网站、同一浏览器配置下；权限恢复由用户主动点击触发，后台不会反复弹授权窗口。
- 文件名附加内容哈希，重复取回不会反复写入；遇到现有同名但内容不同的文件会改名，不覆盖用户文件。
- 面板使用与现有导出弹框一致的 #212121 底色、#1d1d1d 标题栏、8px 圆角和右上角叉号；作品以缩略图展示，可筛选图片/视频、搜索当前目录、按时间/文件名排序和进入子文件夹。每个目录最多读取 1,000 项，最多展示 200 项，可通过搜索缩小范围。断开映射不会删除磁盘文件。
- 打开仓库、生成保存完成和切回浏览器时自动更新，不再保留常驻刷新/重试按钮；仅保存失败且有待保存结果时展示重试。
- 在其他标签页更换或断开映射后，旧标签页下一次保存也读取最新映射。
- 本地文件只在浏览器中读取预览，不因映射而上传到控制面或算力节点。

建议选择固定的作品文件夹。桌面旧入口对应按会话管理的 `ai-sequence-cache` 临时目录，映射到该临时目录并不能改变桌面的清理策略；本次没有修改原桌面项目。更新前网页内存中的历史结果不会自动迁移，新版本接收的生成结果开始自动入库。
