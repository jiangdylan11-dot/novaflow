## 存储与身份

| 数据 | 位置 | 内容与限制 |
| --- | --- | --- |
| 当前任务连续性 | 助手 dataDir 的账号隔离任务文件 | 请求、完整提示词、参数、参考 SHA、结果 SHA、工具及真实评价；不含图片像素或认证 token；200 任务/12 MiB 上限 |
| 专业方法候选 | Supabase | 抽象方法、技能/模型/采样/大脑适用条件、结果摘要证据；不上传完整提示词、聊天、原始图片 |
| 正式方法与技能 | Supabase 不可变版本 + 当前指针 | 方法上限 100 条/技能，完整知识包限 128 KiB；支持历史回退 |
| 最近正式版本 | 助手本地缓存 | 启动及新验证会话后台同步，之后每 5 分钟检查；正常任务只读本地文件/内存 |
| 待提交贡献 | 助手任务 outbox | 最多 200 项；重试不阻断创作，按证据 SHA 确认，防止旧确认覆盖新反馈 |

未建立个人长期经验库。浏览器登录和算力节点绑定是不同身份：安装助手不赋予发布权，也不要求开启算力分享。浏览器 NFS 登录由现有控制面 `/me` 核验，按 AsyncLocalStorage 隔离每个请求。短期活动会话只留在 RAM，用于知识同步，绝不进入模型或任务文件。

普通账号默认不贡献共享方法；账户只有一次性的“允许贡献通用美术方法”授权开关，不需要每次创作选择经验类型。本人已按本次明确要求开启抽象方法贡献。满意、不满意和明确修改要求自然记录；纯评价不会调用大脑，也不会生图。含提问的评价可继续正常对话。

## 候选、筛选和发布

同一次现有绘图推理可返回 `learningMethod`；没有抽象方法时不把整份提示词顶替成方法。提案格式错误或本地日志失败不破坏正常生成。

候选与正式库分离：正面反馈只是候选证据，不是质量验证。必须有不同实际结果及提示词、前次负面评价和后次正面评价，才标记改进。服务端仍将客户端证据作为未受信任的待审信号。

自动过滤规范化重复、已正式发布方法、被回退的方法和没有正面证据的方法；有相反评价、单用户证据的方法重点提示。当前重复检测是规范化文本去重，不承诺识别所有语义同义句。正式经验的负面复用结果通过 `/outcomes` 回流，审核报告显示需要复核的方法。

`package-site.mjs --enable-art-knowledge` 在部署打包前自动生成只读 JSON/中文筛选报告，不发布方法。本人在“账户 → 审核专业经验”选择技能、候选及通过的固定基准记录，准备具体批次，再明确勾选并确认发布。批次 SHA 绑定候选、证据、基准、技能版本及原正式版本，发布事务重复校验并锁定证据，避免审核期间变化。不能用脚本替本人批准正式经验。

候选 API 每账号每小时有证据限额，审核查询当前最多 500 条；尚未做千用户并发压力验收，也没有宣称候选和审计证据已具备无限存储能力。

## 真实验收证据

本机工作目录：`work/art-learning-20261026/`。验收页为 `http://127.0.0.1:4797/`，仅允许访问显式登记的图片，不能读取配对文件、任务日志或凭据。

- 120 项针对性检查、入口检查、运行文件同步与检查通过；自然中文评价补充检查通过。审核 UI 验证勾选前禁用发布、显示正反证据和精确批次，模拟调用只在明确确认后发生。
- 实际 Supabase 登录、授权、去重、候选不自动生效、非发布人拒绝、精确批次批准、两用户缓存、离线重启、回退均验证；生产服务与 RLS 也独立核对。
- 真实打包 UI：有效本机授权、真实 QA 登录、全新未绑定且不分享的节点，参数确认 → 一次 Flash 分析 → 上传原始双图 → 既有 worker 构图 → 一张实际结果 → 真实结果 SHA 回执 → 中文自然评价 → 候选自动上传并确认。规划及应用 119.518 秒，生成任务 63.255 秒，反馈不追加推理。证据：`paired-end-to-end-acceptance.json`。
- 六风格使用同一内容图、各自原参考、同种子、Turbo 8/CFG3、1280×960，全部单次生成且没有修图。冷启动分析约 103–131 秒，生图约 59–66 秒；分开列出加载、推理、释放。经验 CPU 读写为几毫秒，不在生图路径上请求 Supabase。
- 用户此前明确喜欢的 D 图命中动态经验为 0，改进来自专业框架/推理策略，不归功于经验库。

## 当前能力边界

初级框架实现了可审核、可回退、不会阻断生成的共享经验机制，并完成真实界面到云端的闭环。美术结果依旧受模型执行能力影响，候选不保证普遍有效。

知识数据与适用条件独立于大脑；本地 Flash 绘图路径已经实际验证。现有在线智能入口仍只有文字对话，未新增 API 绘图执行适配，不能将“数据可复用”说成“任意 API 大脑已经完成绘图切换”。本次六风格实测的是 Turbo 8 路径，不是对普通 25 步或所有其他模型的验收。

同步失败继续使用最近有效缓存；没有缓存则使用内置专业技能。异常同步不自动重试生图，不回退成其他生成模型，不污染正式经验。
