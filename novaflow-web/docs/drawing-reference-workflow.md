# 绘图参考驱动流程：实现与验证记录

日期：2026-10-23。范围为美工的“绘图”页，UI 设计流程保留原入口。

## 使用方式

- 添加参考图，写一句用途关系，例如“图1用图2画风”，直接生成。
- 单张参考图可写“二次元”等简短效果词；参考用途明确时也允许提示词留空直接生成。任务下拉框已移除，界面不再要求重复选择任务。
- 每张参考仅显示原始图号，没有用途下拉框。由“图1人物、图2画风、图3姿势”等短句自动理解职责；主体、风格、姿势、背景、材质、配色、构图、光影或物件的内部职责仍保持独立。
- 本地分析 / Grok 分析紧跟正向提示词标题行的“历史记录”，不占用输入正文；绘图页移除旧 AI 助手入口和重复“需求分析”文字。“查看分析”放在生成状态旁，窄区域的正反提示词会换行排列，避免标题栏拥挤。原提示词保留；分析结果可查看，不增加优化提示词的二次确认步骤。

## 实际处理链

`runArtGenerate → NovaFlowArtDirection.prepare → 实际视觉分析 → 用途校验 → 参考隔离 → 已有生成路由 → 实际成图检查`。

主体保留完整原图像素，不接受分析模型擅自裁剪；风格使用完整原图以保留五官关系、材质细节和整体照明，材质仍只提取指定表面；姿势使用真实 MediaPipe 关节点；背景使用已捆绑的 BiRefNet 隔离检测到的无关前景；配色使用主色统计；构图和光影分别转换为粗几何和低频明暗。风格图完整输入是明确的职责条件；姿势仍使用骨架，禁止在识别失败时静默回退为姿势人物原图。

画风定义包括绘画语言、眼鼻口比例和概括方式、面部体积及主光方向、软硬、冷暖、对比与轮廓光。单独观察完整风格图的媒介、五官、线条、上色、质感、照明和配色七项实际画法，不再用有限风格关键词代替原画法。主体辨识特征、主要动作、服饰类别、持有物与场景类型取自主体图；人物比例、轮廓、衣褶、背景安排和细节允许重构，成图质量、目标配色和协调氛围优先；五官比例、轮廓概括、头发组织及整个画面的渲染与照明按风格图重绘。允许改变摄影轮廓和写实五官比例，不代表可以更换人物、服装、动作或背景内容。明确的“保持原构图”等要求，或单独的姿势/构图参考，约束相应维度。换风格不继承 UI 精修的空间锁定；主体完整原图仍参与参考条件，不能把空 latent 等同于已消除照片画法偏置。

用户明确的用途是白名单，否定用途是黑名单。辅助图的自由描述不直接成为成图要求；风格使用完整像素并明确禁止借用人物、服饰、姿势、背景和物件，材质和环境只允许有限的相应用途语义进入指令，避免把能量、道具和参考人物引入。姿势图会被单独观察一次，再筛选仅含人体几何的动作描述，转换为明确的正向编辑指令。应用目标必须来自用户原文；主体原有配饰另有保留约束。

图像通过独立输入上传，不复制到任务控制 JSON。参考图、用途、提示词、任务、尺寸或线路在分析期间变化时，旧结果不能提交。取消会丢弃迟到的分析结果。已经开始的后台生成允许用户切换页面。

成图检查比较输出和原始参考。姿势另有独立的实际关节点方向对照，不以语言模型的“通过”结论覆盖明显肢体偏差；少于六个可靠肢体段的局部检测不能成为额外人物。偏差时本地生成最多自动纠正一次；云端不会静默追加第二次付费生成。检查失败或未完成会明确保留状态，不能视为效果验收通过。Grok 分析及成图检查使用现有 Grok 次数。
