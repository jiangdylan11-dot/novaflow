# Flash 本地助手迁移（2.0.101）

绘图、图片反推、动画／视频、H3、UI、音频和 AIFX 的正常本地语言／视觉推理统一使用 Strata 上的 Swift Qwen Flash。各业务原有的格式、布局、动作顺序和生成图构建仍由对应模块负责。PE／NF4 仅保留显式兼容诊断，不作为失败后的自动回退。

## 资源交接

共享会话核验实际模型身份，依次完成加载、业务推理、卸载和进程退出确认。只有资源释放确认成功，返回值才标记 `resourcesReleased`、`generationReady`；取消、超时或卸载失败均不启动生成。生成任务与提示词任务共用互斥资源门。每次模型操作通过独立归属令牌取得控制权；另一实例忙碌拒绝、取消或退出时，不卸载现有拥有者的模型。未加载过模型的实例退出不调用全局卸载。UI 能力查询及已取得分析后的 CPU 编译直接执行，不加载 Flash。

Flash 适配器复用各业务已有架构，不加载旧 PE／30B 权重。UI 原始分析与字段来源保留，CPU 仅投影已明确确定的业务规则。音频改写在进入生成图前由 Flash 完成；正式音频图移除了旧 2B 改写节点，保留 T5Gemma 等实际生成编码器。

## 本机实测范围

硬件为 RTX 4090 Laptop 16GB、64GB 内存。以下是本次单项实际记录，包含加载和释放的时间不能视为纯模型输出速度，也不构成各输入下的固定承诺。

| 实际调用 | 生图／生成前用时 | 已验证范围 |
| --- | ---: | --- |
| 普通视频／H3 文本 | 72.163 秒 | 实际配对 HTTP 入口、动作顺序、独占声音规则、释放；未渲染视频 |
| H3 首尾帧 | 59.759 秒 | 两张完整图片进入模型，返回实际 Strata 身份；未渲染视频 |
| 图片反推 | 65.228 秒 | 实际完整图片和结构化返回；细小身份标记仍可能漏识别 |
| AIFX 材质助手 | 50.575 秒 | 实际视觉理解和配方返回；未渲染特效 |
| 音乐提示词改写 | 47.835 秒 | 原生 Flash 改写，未凭空增加乐器 |
| UI 四阶段全新分析 | 200.130 秒 | 四次独立原生回答，20 个物件及身份绑定；速度仍需改善 |

另有真实 UI 生成：沿用三份已核验的源分析，只重新执行一次美术分析（97.096 秒），再由正常 UI 工作流生成（64.11 秒）。20 个位置、三个人物绑定、购买／金额／旋转等业务信息保留；人物脚部与信息区域仍有遮挡，美术品质尚未获用户验收。不能将它称作四次全新分析后成图。

音频正式工作流实际完成生成，未调用旧 2B。8 秒、88 BPM 的循环请求会按原有完整小节和接缝策略输出约 5.44 秒，不能据此宣称固定时长精确达成；听感未验收。

## 效果与交付边界

统一推理入口不等于风格迁移质量全部达标。用户认可的暗色双图样例保持为单案例基线；明亮及其他参考仍存在偏色、头发偏写实和参考贴合度问题。频段、TeleStyle 及其他隔离试验未通过时，不提升为正式默认路线。

2.0.101 Windows 安装包已构建，实际安装包展开后的 1022 个文件与构建产物逐一核对，已安装文件同样逐一校验。最终安装版实际配对 HTTP 验证：UI 能力查询约 1 毫秒且没有加载模型；视频／H3 文本由实际 Flash 处理，加载至释放共 73.129 秒，其中模型请求 25.666 秒；所有自有端口退出，借用的 Comfy 服务保持运行。本地文件更新保留完整备份，不修改 HKLM 卸载登记，系统卸载列表可能仍显示 2.0.98。源码、当前开发工作台、已安装文件及系统安装登记分别核验，不以其一替代其他层。

资源归属修复经 45 项 Node、41 项 Python 针对性检查，覆盖两个实例竞争、取消、部分加载失败和释放重试。宿主硬崩溃后，新实例不会自动接管旧令牌或停止旧进程；此类孤儿进程需使用控制器的显式 `--legacy-diagnostic` 人工恢复，不能把新实例的普通退出当作全局清理。

环境打包脚本已包含固定版本的 Strata 控制与推理引擎及依赖核验。本次没有重新构建多 GB 环境包，也没有发布网站或推送代码。旧助手权重仅在所有实际消费者迁移核验后清理；生图、视频、音频编码器与用户 LoRA 不属于助手权重清理范围。
