# Flash 绘图负向上下文（2.0.102）

此前原生双图绘图线路把框内负向词交给生图模型，却未把它交给 Flash 分析。旧分析或固定质量规则也可能写过该字段，因此不能默认将其当作用户亲写的要求。

本次将非空的现用负向词加入同一次 Flash 请求，按主体／风格重排同步映射参考图号，来源标为 `unknown`。明确它是现用生图排除上下文，不是待绘制内容，不自动清空或改写。原生正向回答、实际生图负向及冻结 v10 系统保持原文；空值、缺失值和全空白值的模型请求逐字保持旧行为。

审计只记录是否提供、来源及摘要，不在新增字段重复保存负向全文。13 项针对性 CPU 检查覆盖传递、图号、来源、一轮推理、空值稳定性和生图参数保留。

这项修复补齐输入上下文，不能解释或解决全部风格失败；已有空负向失败样例保持原判断。[全模块迁移说明](flash-local-brain-2.0.101.md)仍适用，生图编码器与绘画模型未因此更换。
