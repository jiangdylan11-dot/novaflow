# Foart 2.0.159 界面一致性修正

日期：2026-10-30。助手/网站版本 2.0.159，后台管理版本 3.0.34。

## 最终规则

- 主生成按钮（视频、音频、特效、绘图、UI 生图、生成新资源）使用实心绿色 `#1ea672`，悬停 `#24b682`，禁用只降低透明度。
- 普通按钮、工具压缩/转换、导入、保存到资源列表、视频抠图保存、美工导出使用统一灰色。原有透明导航/分组标题保持透明，按钮无描边。上传区保留虚线，开关保留实心绿/灰状态。
- 视频/音频二级入口选中状态采用统一深绿。美工模型和 LoRA 间距与音视一致，主生成按钮补图标。顶栏胶囊去投影，小桃入口保留轻微阴影。
- 粒子面板底色、滚动条、嵌入骨骼编辑器按钮统一；贴图卡片去蓝底，内置图标缩到 24px，静态长说明精简，动态状态/错误保留。
- 视频新增轨道按钮居中，轨道名称 11px，音轨背景改中性灰。小桃标题、机器人、模式、状态反馈去粉色，发送用灰按钮。

## 行为修正

- 特效冻结宿主滚动时排除版本号按钮，避免裁掉分割线。
- 切换版块隐藏仓库待保存浮动提示，待保存文件仍留在原队列。
- 两个特效库的右上角统一使用关闭图标。
- 特效导出同时识别旧 Spine 与新“动画工程”名称，移除工程导出标签；若沿用了该标签，回到序列帧。切回动画场景时恢复工程导出。
