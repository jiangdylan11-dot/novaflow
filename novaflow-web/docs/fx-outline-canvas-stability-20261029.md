# 特效轮廓尺寸与扫光帧数稳定性修复

用户截图对应两条复现：特效模板里先描图片轮廓，再从 1:1 切换“跟底图”或自定义画布；骨骼动画扫光中不勾素材，直接打开生成特效，再点图片轮廓或需要底图的效果选图，修改帧数后图与光的位置、形状跳变。

## 根因与处理

- `setCanvas → keepOutlineIn` 原先只按画布中心差平移轮廓，底图却由 `basePlacement` 随新画布等比缩放。现在切换前保存底图放置矩形，`reframeProject` 对轮廓、孔洞、用户改点和起点使用与底图相同的缩放和平移，圆角与内外扩距离同步缩放。保留点数、尖角/平滑标记及效果参数，不重新描边覆盖用户编辑。没有底图时保留原居中及过大形状入框规则。
- 空扫光入口点击“图片轮廓”和需要底图的效果，原先绕过工程底图选择器而直接使用普通模板的本机上传路径，保留 640 画布/0.7 比例。随后改帧数才调用 `applySweepCanvas`，突然改为原像素加边距，且轮廓未同步。现在三个选图入口统一走 `chooseBase`：扫光使用工程选择器，按原像素规范画布后才描轮廓；普通模板仍使用本机上传。
- 帧数和时长只更新时间字段、缓存及播放采样，不再改画布或底图比例；帧数改变时保留归一化播放进度，循环和一次性分别按各自采样规则处理。只有边距等空间变化才重新映射已有轮廓，保留编辑点和起点。
- 连续换底图时按实际选图顺序标识请求，解码提交及后续效果回调只接受当前请求；旧解码、旧错误和旧效果不会覆盖新选择。关闭窗口或移除底图会使在途加载失效；打开后取消新选择不会废掉之前已选择的加载，没有会被取消操作永久占住的 busy 锁。
- 骨骼工程的预览、选底图、改帧数不写入骨骼、插槽、动画或撤销历史；确认生成/写入仍走原有显式按钮。没有修改效果画法或颜色。

## 验证

- 新增几何回归 7 项、扫光状态/时间/异步回归 21 项，合计 28 项通过。
- 另运行已有形状、外扩、图片描边、精确画布任意帧数、循环采样及边距相关测试，6 项通过。
- 合成图保留孔洞、独立块和人工改点；反复切换画布后底图局部坐标不漂移。真实 `FX.prepare/renderFrame` 经过缓存预热后，几何及像素与底图贴合率 IoU 均大于 0.94。
- 流星效果在 80×80 CPU 渲染中，循环/一次性改帧数后同 phase 像素逐字节一致；覆盖跨圈、分数播放位置、首尾帧和 2→120 帧。时长改变保留播放位置。
- 完整效果库回归启动后耗时较长，已停止；最终采用上述与改动直接相关的单进程低分辨率验证。没有启动生图模型、GPU 生成或付费请求，NovaFlow 本机服务保持停止。
