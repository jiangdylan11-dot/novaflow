## 修复及确切依据

- 卡片底部统一一条黑色 65% 透明名称条，12px / 400 字重 / 18px 行高，同样的字体、颜色、位置，显示“参考图 1”“参考视频 1”“参考音频 1”。不叠文件名或分辨率；原文件名保留 tooltip 和元数据。图片仍走原生 img 分支，原始 src 不变。
- 视频、音频使用同尺寸 14px SVG，固定在预览区域左上同一偏移；秒数居中缩为 12px。正式运行时的上传归一化会改写 div/span 样式，现于同一归一化流程末尾只规范多参卡片的内部内容；未改横向几何函数。
- 之前的受控测试没有执行品牌运行时的 ensureStyle 注入。加入实际完整 CSS 后，已复现 hidden 元数据 video 被高优先级上传媒体规则重新显示：测试的纯蓝视频出现在秒数背后。元数据探测现改为不挂入文档的 video/audio，卡片内不再有原生媒体表面；SVG 及其所有图形最终 fill 均为 none，秒数及图标背景透明。此证据证明存在该冲突，不能声称已对用户原素材的白色矩形作完整实机复现。
- @ 的直接阻断条件已确认：H3 素材快照缺少 available，正式挂载器要求所有资源 available，否则卸载编辑器。补齐 available:true；卡片、候选、插入标记和 H3 解析器使用同一带空格名称，同时兼容旧别名。
- 删除时按 sourceId 重新编号并改写引用；被引用素材被删除后保留明确的“已删除素材”标记，生成编译器将其列为失效引用并阻止提交，不静默指向另一份素材。
