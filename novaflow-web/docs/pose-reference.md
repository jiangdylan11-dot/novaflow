# 增强：姿势参考

入口：美工 → 绘图 → 增强 → 姿势参考。此工具在浏览器中摆放灰色 3D 人偶，不需要 ComfyUI 或生成模型。

- 姿势库提供 136 个上游预设及预览图，支持名称搜索和分类筛选；点击应用骨骼和预设镜头方向，再继续调节关节。普通姿势按当前体型和场景自动适配全身，特写预设保留原有构图。
- 支持添加、选择、删除多个人物（最多 32 人），可在列表或画布中切换人物。每个人保留独立骨骼、体型、位置和姿势撤销记录；位置 X/Y/Z 用于安排多人构图。允许删除最后一个人物后重新添加。
- 每个人可独立选择女性、男性或中性，以及成人或儿童。体型使用 MakeHuman 对应 morph 的真实网格与骨架，统一脚底基线；切换体型保留骨骼旋转，重建与旧骨架有关的位置及 IK 目标，并清空该人物旧骨架的撤销记录。
- 「移动人物」或点击脚下整体根骨可显示世界坐标移动手柄，拖动 XYZ 箭头或平面移动整个人物；其他关节保持旋转操作。
- 移除快速姿势和关节选择下拉框，直接点击人偶关节进行旋转，支持 IK 手脚拖动、FK 关节角度和三种手势。姿势库只应用到当前人物。
- 左键拖动空白处旋转镜头，Ctrl＋左键拖动平移（也可从人偶上开始），滚轮缩放；右键控制已取消。点击人偶或操作手柄时普通左键优先用于关节操作。
- 默认显示地面网格和 XYZ 坐标轴，空间辅助线默认常驻，不设置开关；镜头预设与「适配全部人物」会将全场景纳入构图。
- 弹窗保留自己的布局与鼠标事件，手势和分类下拉框使用浏览器原生选项，不进入工作区的全局下拉框浮层。
- 导出 PNG 使用当前视角和输出尺寸，隐藏操作手柄、关节和网格。保存/导入姿势文件保留全部人物、当前选择、位置、关节、根骨位置、共用镜头及输出设置；兼容旧单人文件，最近场景也保存在浏览器本地。空间辅助线不进入导出图。
- 「用作姿势参考」填入当前模型允许范围内的第一个空参考位，然后切换到图生图。参考位已满或生成正在运行时提示用户，不覆盖已导入图片。
- 不更改生成模型、2511 路由、采样参数或用户提示词。模型最终对姿势的跟随程度仍需要实际出图验证。

## 上游与更新

3D 核心直接来自 [AHEKOT/ComfyUI_VNCCS_Utils](https://github.com/AHEKOT/ComfyUI_VNCCS_Utils)，MIT；Three.js r160 为 MIT。MakeHuman 图形资产为 CC0。核心、依赖、许可和原始文件 SHA256 保存在 `renderer/vendor/vnccs/`。

为避免下载整个 38 MB morph 包，使用上游算法离线生成约 1.4 MB 的中性成人静态人偶。上游年龄不是 0..1 参数；其完整成年形态对应 1..90 范围的中点 45.5。更新脚本固定该形态，避免混入婴幼儿/儿童 morph。

姿势库是所给仓库引用的 81 个社区预设加 55 个随包预设。原始 JSON 和预览图原样保留在 `renderer/vendor/vnccs/pose_library/`；`index.json` 记录每项来源、提交及 SHA256。预览保留上游画面；应用时只读取姿势和镜头，不改变人偶体型；非默认体型按骨骼旋转适配，避免预设的成人骨骼位置拉伸当前人偶，也不导入上游提示词。第三方姿势库各自保留原作者条款，不能统一视为核心的 MIT 许可，详见 `NOTICE.txt`。

更新本地副本：

```powershell
node novaflow-web/tools/vendor-pose-studio.mjs
node novaflow-web/tools/vendor-pose-library.mjs
node --test novaflow-web/tests/e2e/pose-reference.test.mjs
npm run sync:runtime
npm run check:runtime
npm run check:entry
```

体型变体由 `node novaflow-web/tools/vendor-pose-bodies.mjs` 从本机缓存的固定 morph 源派生；运行 `vendor-pose-studio.mjs` 时也会同步生成。`body-types.json` 记录六种体型的参数和 SHA256，运行时不加载大型 morph 包。

更新脚本仅下载静态开源资源，不安装 ComfyUI 节点或生成模型。正式发布、打包和部署仍遵循仓库版本流程。
