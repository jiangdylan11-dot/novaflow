# Foart 品牌替换与发布

2026-10-29，按用户选定的橙色几何方案替换品牌。软件显示名称为 **Foart**，后台为 **Foart 后台管理**；图形字标沿用批准的小写设计。主程序使用深灰底橙色图形，后台桌面、任务栏和安装器使用深灰底白色图形。

## 改动

- 新增描摹批准原稿的 SVG 路径母版、透明 PNG 和 8 个尺寸的 Windows ICO，覆盖网页首屏、登录页、编辑器、启动助手、托盘、后台、安装器、快捷方式和工程关联图标。
- 联系卡片替换品牌标题，嵌入原始二维码并裁掉旧标题；二维码原始字节保留。
- 用 `tools/sync-brand-assets.mjs` 同步各入口和旧资源别名，网页和后台构建自动同步。后台安装资源清单包含字标和独立白色 ICO。
- 保留原 appId、授权载荷产品标识、协议、项目扩展名、用户数据目录、会话存储键和内部 API，继续沿用原有配置。
