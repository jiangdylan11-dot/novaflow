# 小桃音视控制接入与验收（2026-10-30）

本地智能已接入音视的真实操作。此次更新源码和开发运行目录，未打包安装程序、未部署网站，版本仍为 2.0.169。

## 接入范围

- 视频生成：读取当前模型、参考素材、画幅等配置，设置提示词与时长，提交原有视频生成流程；完成回执只接受本次任务的真实输出。
- 视频/音频时间轴：读取实际片段与选区，导入资源、裁切、分割、移动、变速、复制、移除、淡入淡出和导出。
- 音频：生成音乐/音效，调整片段音量，混音导出；可把视频资源的音轨导入音频时间轴处理。视频编辑器自身没有片段音量接口，相关请求应使用音频编辑器。
- 在线智能目前仍提供对话建议；执行操作需要选择本地智能。本次没有调用付费云端生成。

小桃使用受限的 `media` 工具协议；模型不能提供任意代码、路径或请求地址。操作绑定当前快照，素材、时间轴或配置改变会拒绝旧方案；方案不能重复执行。生成前须确认本次模型资源已释放。停止生成仅取消当前调用所属任务；已完成的剪辑步骤不自动回滚，失败信息会说明已完成步数。

明确的操作请求要求原生工具调用；缺少材料或目标不清时通过澄清工具返回问题。实测中曾发现模型只给出未来式文字答复而不调用工具，已修正协议并重新完成导入、裁切、导出验收。普通讨论不会执行应用工具。

## 实际验收

使用独立的本地工作台、有效本机授权、实际 Flash 模型、本机生成工作流和 Chromium 中的原有编辑器；未伪造登录或生成结果。

1. 中文指令生成蓝色立方体旋转视频，任务 `36ff7db0-8457-418c-9d41-1a3f0dc35a1f` 实际完成；检查输出画面，480 × 864、24 FPS。
2. 小桃将该实际输出导入视频时间轴，裁切素材 0.2–1.4 秒，时间轴长度变为 1.2 秒；实际导出 MP4，109,683 字节。最终运行文件另用原有编辑器重新导出，文件可完整解码。
3. 小桃实际生成树叶沙沙声音效，任务 `0f4c4e67-8e19-40f4-a625-0b10f633ef4e` 完成，自动进入音频时间轴。
4. 中文指令将该音频片段音量改为 50%，淡入/淡出各 0.2 秒，实际混音导出 WAV，221,576 字节、44.1 kHz、双声道。
5. 比较原始音频与实际导出 PCM 的增益/包络；考虑 WebAudio 重采样后的低频信号，包络比例 1.00012、相关系数 0.99822，符合指定的 0.5 增益和淡入淡出设置。

生成模型沿用现有时长策略，并非采样级精确：测试的视频请求 2 秒，实际素材约 2.33 秒；音效请求 2 秒，实际解码约 1.26 秒。时间轴和导出使用实际解码时长，本次未修改生成模型的时长策略。音乐接口通过参数与任务合约检查，本次 GPU 实测音频类型为音效。
