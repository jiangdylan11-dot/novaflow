## 调用链证据

- `novaflow-web/renderer/xiaotao-art-agent.js` 的 `sendMedia` 显式拒绝 `state.provider !== 'local'`。图片的执行意图分支也只允许 local；本次“生成一张”的措辞落入在线 chat，因此收到不能生成的诚实文字回答。
- `novaflow-web/renderer/novaflow-web-runtime.js` 的 `companionCloudChat` 只接受 `mode: 'chat'`，响应能力明确为 `tools: false`。
- `novaflow-web/packages/shared/src/companion-chat.mjs` 是计费多模态对话服务，未提供应用执行工具，还会拒绝模型返回的 `function_call`。
- 当前没有在线执行回执、图片/视频输出 ID，也没有可用于下一轮的实际结果绑定。因此不能将文字记住约束认定为“接着上次结果制作”。这与本轮此前已通过的 Key 同步、在线对话连通是两项不同验收。
- 图片回答未虚构生成成功；视频显示了未执行错误，但底部仍保留上次文字对话的“已回复”状态，且被拦截的视频请求没有记入对话。这也是需要一并处理的界面一致性问题。
