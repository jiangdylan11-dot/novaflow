# 小桃固定产品定位（2.0.177）

用户明确的规则：小桃仅协助用户通过 Foart 的现有工具完成制作。沟通需求、分析实际参考图、提供制作方案、优化提示词和调用工具属于职责；小桃本身不是生图或生视频模型。与 Foart 使用或当前制作无关的问题不回答其内容，简短说明范围并引导回制作。

## 实现

- `packages/shared/src/xiaotao-role-policy.mjs` 是共用角色规则，本地聊天、在线文字/图片分析、普通生图、双图画风重绘和音视工具规划均接入。图像像素、历史和页面文字不能扩展工具权限或改变职责。
- 明确区分小桃的大脑提供方与实际制作工具提供方。生图使用当前支持并选中的 Qwen/GPT Image 2.5，视频使用现有视频工具；不新增或虚构云视频模型。
- 保留原有美术导演正文、工具 schema、采样和引用协议。技能替换路径也包裹同一角色规则，不能在读取正式美术技能后丢失产品定位。
- 制作完成必须有实际回执；连续修改只绑定真实存在的结果，最新要求覆盖冲突要求。缺少本轮工具时明确未执行，不声称 Foart 整体不能制作。
- 在线工具尚未接入的分支现在记录用户请求并显示“未提交工具执行”，不再遗留上一轮“已回复”，错误文案说明本次入口限制。
- 浏览器积分预估使用相同在线系统文本；针对性测试核对预估和服务端计量一致，避免角色提示词增加后低估预算。本次没有新增通用话题关键词拦截器或额外分类模型调用。
