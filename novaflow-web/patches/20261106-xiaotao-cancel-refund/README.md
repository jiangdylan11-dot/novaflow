## 后端 / 网页

- 只退服务器自己能确认的失败：规划没返回可用方案（或这一步不支持）、对话/风格分析的回答不可用、请求已中止或登录已变化。这些情况下用户什么都拿不到。
- 网页取消（比如页面上的工具没跑完）照常按已用量收费：失败是网页自己说的，服务器核实不了，不能凭它退款（Dylan：否则就是白用大脑的漏洞）。
- 扣费为 0 时不显示"本次扣费"。
- 必须先执行数据库补丁再部署后端，否则退款调用会找不到函数（报"账单状态待核对"）。
