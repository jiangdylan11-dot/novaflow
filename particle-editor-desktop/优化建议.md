# 粒子编辑器桌面应用优化建议

## 1. 项目结构优化

### 当前问题：
- 两个独立目录管理不便
- 构建脚本复杂
- 依赖管理分散

### 建议方案：
```bash
particle-editor/
├── src/                    # 前端源码
├── electron/              # Electron主进程代码
├── scripts/              # 构建脚本
├── package.json          # 统一依赖管理
└── README.md
```

### 具体修改：
1. 合并package.json，使用workspaces或条件依赖
2. 统一构建流程
3. 简化开发环境配置
